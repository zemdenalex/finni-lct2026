# Известные ограничения и план развития

> §5 п.11 ТЗ. Оценивается по §8.5: «честное описание ограничений и реалистичный план».

Финальная версия. Документ описывает сборку, которая передаётся на экспертизу: модель «7 дней» (неделя из семи игровых дней), профиль баланса
«средний». Раздел 1 — чего в сборке нет или что в ней выключено; раздел 2 — ограничения, принятые осознанно; раздел 3 — план развития после хакатона.

## 2. Ограничения, принятые осознанно

| Ограничение | Почему так |
|---|---|
| У курьера и программиста три варианта сложности (за вещь); у кассира, консультанта, бухгалтера и садовника — ступени сложности по опыту (0 / 2 / 5 хороших смен) | Все системы собраны; уровни 2–5 — в плане развития |
| Цены не индексируются, карманные фиксированы | Решение по экономике: расходы растут только по выбору ребёнка (еда, жильё, питомец), доход — за хорошую работу и переезд |
| Лимита смен в неделю нет | Смены держат силы и настроение: смена консультанта стоит 6 ⚡, а сон возвращает не больше 20 |
| Голод не пугает | Сытость есть (0–100), но голодный Финни утром лишь чуть слабее и грустнее (−2 ⚡ и −2 😊); он не болеет, не убегает и не «умирает», а если ребёнок не выбрал еду, ужинает домашним меню недели. ТЗ §2 и §3.5 запрещают страх за питомца (обоснование — 08-ux-ui.md, раздел 2) |
| Учебный контент обновляется только новой сборкой | Сервера нет по ТЗ (§3.2.4); контент лежит в сборке, приложение офлайн |
| Один детский профиль на устройстве | Облака и аккаунтов нет; отдельного профиля для демо тоже нет — режим проверки играет в то же сохранение |
| Нет аналитики и телеметрии | §3.5: детское приложение не следит за ребёнком |
| Нет ежедневных серий, таймеров, рейтингов | §2.7.3 и опрос: детям не нравится «заходить каждый день» |
| Звук: щелчок с вибрацией и тихая фоновая музыка | Оба выключаются в настройках («Звуки», «Музыка»); важное не передаётся только звуком |
| Питомцы-резерв (жабка, змея, аксолотль) | Числа есть, в каталоге к демо — пять питомцев |
| Слова «конверт» и «очки роста» остаются в сборке | Они стоят в названиях кода и в части текстов; в новых подсказках мира те же части названы «Нужное», «Хочу», «Копилка» |
| Раздела «Взрослым» в сборке нет (`adult.section` = false); пример на умножение закрывает в «Настройках» «Режим проверки» и «Начать игру заново» | Барьер в прототипе — пример для взрослого (требование ТЗ 2.5.12); любой такой барьер обходится калькулятором, поэтому в развитии вход взрослого переносится в отдельное приложение родителя, связанное с детским устройством |

## 3. План развития после хакатона

### 3.1. Идеи эксперта и отложенное осознанно

1. **Друзья.** Эксперт предложил: делиться с друзьями, вместе что-то проходить, соревноваться. В этой версии общения и рейтингов нет (ТЗ §2.7.3, раздел 5).
2. **Страница родителя.** По итогам консультации родительский контроль не обязателен; мысль — кнопка «отправить родителю» на странице статистики. В сборке её нет, раздела «Взрослым» в сборке нет, пример на умножение закрывает только «Режим проверки» (раздел 2).
3. **Финансовые инструменты** — постепенно, для тех, кто много отыграл: банк, накопительные счета, затем кредиты, возможно акции.
4. **Уровни 2–5 профессий** (мини-игра выгульщика уже есть — «прогулка по клеткам»); усложнение мини-игр по стадии (сейчас стадия поднимает оплату и цены, а задания не усложняет — 06-formuly.md).
5. **Привязка контента к Единой рамке:** построчная привязка каждой строки таблиц 07-obrazovatelnyy-kontent.md к области, категории и уровню рамки; отдельные наборы вопросов для раздела взрослого по каждой из трёх тем.
6. **Проверка на детях** 7–11 лет по §8.4 и правки по её итогам.
7. **Ежедневные дела** (холодильник, «отдохнуть дома») — уже в коде за флагом `day_cycle.daily_activities`.
8. **Экран наград** — включён в сборке; числа наград (18, с баффами) нужно сверить на детях.

### 3.2. Комната и главный экран

9. Каждую комнату можно будет обставить купленными вещами — комната показывает рост и характер ребёнка и его героя. Сетка, вкладка «Комната» в магазине и режим «Расставить» уже есть в коде за флагом `room.customize` (раздел 1).
10. Категории вместо плоской панели — сделано частично: нижнее меню «Дом · Город · План · Мой путь · Ещё»; остаются места для прогулки каруселью у города.
11. Поворот камеры по комнате (арт).

## 4. Вопросы к заказчику

Открытые вопросы и ограничения, требующие консультации заказчика (§7.1 п.7), собраны в
рабочем документе команды (в этот репозиторий не входит): обезличенное сравнение против работы без интернета;
считается ли механика вне ТЗ подменой основной; граница манипулятивной мотивации; формат отчёта о проверке
на физическом устройстве; засчитывается ли контент, который создаёт сам ребёнок; возрастная вилка 7–11 внутри
одного приложения; насколько глубокой должна быть роль взрослого. Доступ экспертов к коду вопросом не является:
репозиторий публичный.
