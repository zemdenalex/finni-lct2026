## 2. Ручные тест-кейсы — Приложение А

Каждый шаг проходится на физическом телефоне, из установленного release-APK.

| № | Действие | Ожидаемый результат | Факт |
|---|---|---|---|
| A.1 | Установить APK (Play Защита — [01, «Установка APK»](01-readme.md#установка-apk-на-телефон)), открыть | Онбординг объясняет цель и три решения: нужное, хочу, отложить | 🟡 |
| A.2 | Ввести ник | Спрашивается только ник; имени, возраста, телефона нет | 🟡 |
| A.3 | Выбрать облик и имя Финни | Превью меняется сразу; имя видно на главном | 🟡 |
| A.4 | Получить первые карманные, выбрать цель | 400 в конвертах, 200 подарка в ЦЕЛИ; на доске видны смены | 🟡 |
| A.5 | Разложить по НУЖНО / ХОЧУ / ЦЕЛЬ | Больше доступного не разложить; остаток виден | 🟡 |
| A.6 | Смена консультанта: в комнате «Работа» (задания ТЗ) → доска «Требуется…» | Ставка видна до игры; после — урок первым (виден без прокрутки на 360×640 ×1,3), под ним оплата и объяснение; отложить руками — «в копилке» | 🟡 |
| A.7 | Купить еду и «хочу»; попробовать купить дороже, чем есть | Списания нет; «не хватает N» и варианты | 🟡 |
| A.8 | Пополнить цель в копилке | Накоплено и «осталось» меняются | 🟡 |
| A.9 | Закончить неделю, открыть итоги | Счета, план против факта, очки роста, причина настроения | 🟡 |
| A.10 | «Спать» → новая неделя; несколько недель подряд | Новая стадия после серии недель, с объяснением | 🟡 |
| A.11 | Закрыть приложение и открыть снова | Баланс, цель, история, стадия те же | 🟡 сохранение подключено (`openSavedWorld` в `lib/main.dart`, `test/world_save_test.dart`), на устройстве не проверено |
| A.12 | Раздел взрослого → «Начать игру заново» | Сначала подтверждение: весь прогресс на устройстве будет стёрт. После — онбординг с нуля. Отдельного профиля для проверки нет, сохранение одно | 🟡 |

Дополнительно:

| Кейс | Ожидаемый результат | Факт |
|---|---|---|
| Режим полёта, весь сценарий | Работает полностью | 🟡 |
| Системная кнопка «назад» на каждом экране | Нет тупиков и выхода из приложения без подтверждения | 🟡 |
