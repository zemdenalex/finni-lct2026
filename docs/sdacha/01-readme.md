## Установка APK на телефон

APK подписан ключом команды (`CN=LCT 2026 Team`) и не публиковался в магазине, поэтому Android предупреждает дважды.
Проверено на телефоне участника 28.09: без шага 3 установка блокируется.

1. Скачать APK из релиза репозитория и открыть файл.
2. Разрешить установку из этого источника (браузер или «Файлы») — Android откроет настройку сам.
3. Если появится **Google Play Защита** и заблокирует установку: **«Подробнее» → «Всё равно установить»**.
4. Проверить, что файл тот же, что в релизе: SHA-256 рядом с APK в описании релиза
   (Windows — `certutil -hashfile <файл> SHA256`, Linux/macOS — `sha256sum <файл>`).

Если установить не получается — та же сборка в браузере: https://finni.archifex.space/demo/.

## Назначение

Ребёнок помогает Финни жить самостоятельно в маленьком городе. Каждую неделю приходит
стипендия за учёбу — 400 монет. Её надо разложить по трём конвертам: **НУЖНО**
(еда, жильё, корм питомцам), **ХОЧУ** и **ЦЕЛЬ** (накопления). Потом ребёнок решает, на что
тратить силы Финни: работать сменами в городе или отдыхать. Копить можно на питомца,
транспорт или жильё получше.

Неделя — это не календарь, а запас энергии ⚡. Неделя кончается, когда сил не хватает ни на одно
действие или когда ребёнок нажал «Спать». В конце недели оплачиваются счета, а план
сравнивается с фактом. Каждая неделя приносит очки роста, и по ним Финни переезжает:
«В деревне» → «В городе» → «В Москве».

Три ресурса: 💰 монеты, ⚡ энергия (0–14), 😊 счастье (0–100). Все формулы описаны в
[06-formuly.md](06-formuly.md).

**Жёсткие границы ТЗ.** В игре только игровая валюта. Нет реальных платежей, рекламы,
подписок, случайных платных наград и общения между детьми. Персональные данные не собираются,
приложение не ходит в сеть, всё хранится на устройстве. Подробно — в
[09-razresheniya-i-dannye.md](09-razresheniya-i-dannye.md).

| `app/finlit/lib/domain/world/contract.dart` | Контракт мира: снимок ресурсов, действия, результат с причиной |

| `app/finlit/assets/content/world/` | Копия `content/*.json`, которая едет в сборку |
| `app/finlit/test/` | Автотесты: домен, экраны, контент, доступность, манифест |
| [`content/`](../../content/) | Учебный контент и все числа экономики: `economy.json`, `jobs.json`, `events.json`; симулятор баланса `sim/economy_sim.py` |
| [`assets/`](../../assets/) | Исходники пиксель-арта (здания, комната, Финни, питомцы) и реестр `registry.json` |

Числа в коде не пишутся: экономика, работа и события читаются из `content/*.json`.
Чтобы добавить событие или поменять цену, достаточно поправить JSON (ТЗ 2.5.14), логику
трогать не нужно.

## Быстрый запуск

Нужны Flutter 3.41.7 (на нём собирает CI) и Android SDK. Полные требования к окружению — в
[02-okruzhenie-i-sborka.md](02-okruzhenie-i-sborka.md).

```bash
cd app/finlit
flutter pub get
flutter analyze        # ожидается «No issues found!»
flutter test           # все тесты зелёные
flutter run            # на подключённом телефоне или эмуляторе
```

🔴 В пути к репозиторию не должно быть кириллицы: на таком пути Flutter роняет analysis server
с `FormatException`, и в сообщении про путь не сказано ни слова.

Релизный APK:

```bash
cd app/finlit
flutter build apk --release
# → build/app/outputs/flutter-apk/app-release.apk
```

Без `android/key.properties` релиз подписывается отладочным ключом, и такой APK отдавать нельзя.
Как подключить ключ и проверить подпись — в [02-okruzhenie-i-sborka.md](02-okruzhenie-i-sborka.md).

Баланс экономики проверяется симулятором (нужен только Python 3.10+):

```bash
python content/sim/economy_sim.py --weeks 5
```

## Как проверить сценарий Приложения А

Приложение открывается сразу в новом мире: знакомство (6 шагов) → комната Финни.

**Режим проверки для эксперта:** в комнате значок замка «Взрослым» (справа в строке ресурсов) → решить пример на
умножение → раздел «Взрослым» → «Управление» → **«Режим проверки»** (экран «Проверка», маршрут `/w/demo`). Там:

- «Автопилот»: «Сыграть 1 неделю», «Сыграть 5 недель», «Дойти до 3-й стадии» — недели проигрываются теми же действиями,
  что у ребёнка, журнал автопилота показан ниже; «Полная ⚡», «Закончить неделю»;
- «Приложение А: N из 12» — отметки шагов по журналу игры;
- «Экраны» — переход на любой экран мира;
- «Начать игру заново» — стирает прогресс после подтверждения (отдельного тестового профиля нет).

Шаги и ожидаемый результат — в [10-testy-i-proverka.md](10-testy-i-proverka.md). Без установки — веб-демо
https://finni.archifex.space/demo/.
