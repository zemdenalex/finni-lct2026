Реестр `id → файл` для кода — **`registry.json`**. id зданий совпадают с экранами из
`docs/game/screen-city-iso.md`, id питомцев — с `content/economy.json` (`pet_kitten`, `pet_hamster`, `pet_dog`, `pet_fish`, `pet_turtle`).

| Группа | Где | Состояние |
|---|---|---|
| Здания города (7) | `city/d072/` | 🟢 выбрано 0.72 (Денис, 26.09); `city/d045/` — для сравнения |
| Финни, виды A1/A2/A3 | `finni/gpt/` | 🟡 из ChatGPT-партии 26.09-2: 4 облика на вид (12), `idle-1..4`, у A1 ещё `walk`; вид выбирает ребёнок. Старый черновик кодом — `finni/` |
| Питомцы | `pets/` | 🟡 хомяк, котёнок, собака, рыбка, черепаха: `sleep`, `wake` (у рыбки `sleep` — плавает) |
| Комната сбоку (S1) | `room/` | 🟡 4 варианта 272×168, выбирает Денис; слоты Финни/питомца/предмета — `room/slots.json` |
| Пробы и исходники генераций | `gen-test/` | черновики, в приложение не идут |

## Как устроены файлы

- Спрайт-листы — горизонтальная лента; прямоугольники кадров и теги анимаций — в `.json` рядом
  (Aseprite `json-array`). Исходник для правки — `.aseprite`.
- Здания — один PNG с прозрачным фоном, пиксель 1:1. Якорь — низ по центру земельной плитки.
  Масштабировать только целым числом и `FilterQuality.none`, иначе пиксели поплывут.
- Пересобрать здания: `python tools/iso_building.py` → `tools/sdxl_pixel.py --init … --denoise 0.72`
  (локальный ComfyUI) → `tools/pixel_clean.py --px 8 --colors 40`.

## Известные дефекты

- У A2 и A3 нет ходьбы: нужен лист «спереди/сбоку/сзади/шаг» из ChatGPT, как у A1.

- Кино и парк перегенерированы (seed 11, в негативе «letters, words»): псевдобукв на вывеске нет. В парке 3 дерева вместо 4, зато пруд, скамейка и фонари.
- Вывеска кино без слова «КИНО» — здание узнаётся по гирлянде и афишам; подпись даёт интерфейс.
