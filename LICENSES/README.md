# Лицензии сторонних компонентов

Полный перечень — [docs/sdacha/12-storonnie-komponenty.md](../docs/sdacha/12-storonnie-komponenty.md):
библиотеки, шрифты, изображения (включая сгенерированные ИИ, с сервисом и моделью), звуки.

| Файл | Что |
|---|---|
| `OFL-Onest.txt` | SIL Open Font License 1.1 — шрифт Onest (он же лежит в сборке, `app/finlit/assets/fonts/`) |
| `OFL-Unbounded.txt` | SIL Open Font License 1.1 — шрифт Unbounded |
| `pub-deps.txt` | Дерево Dart-зависимостей с версиями (`flutter pub deps --style=compact`), снятое при экспорте |

Тексты лицензий Dart-пакетов Flutter показывает сам: в приложении — «Настройки → Лицензии».
