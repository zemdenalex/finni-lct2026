## Установка APK на телефон

APK подписан ключом команды (`CN=LCT 2026 Team`) и не публиковался в магазине, поэтому Android предупреждает дважды.
На телефоне участника команды 28.09 без шага 3 установка блокировалась.

1. Скачать APK по ссылке https://finni.archifex.space/eksperty/files/finni.apk и открыть файл.
2. Разрешить установку из этого источника (браузер или «Файлы») — Android откроет настройку сам.
3. Если появится **Google Play Защита** и заблокирует установку: **«Подробнее» → «Всё равно установить»**.
4. Проверить, что файл тот же, что выложен: SHA-256 лежит рядом с APK (`finni.apk.sha256`)
   (Windows — `certutil -hashfile <файл> SHA256`, Linux/macOS — `sha256sum <файл>`).

Если установить не получается — та же сборка в браузере: https://finni.archifex.space/demo/.

## Назначение

Ребёнок помогает Финни жить самостоятельно в маленьком городе. Каждую неделю приходит
стипендия за учёбу — в сборке 820 монет (выбран профиль баланса «средний»; без профиля, по файлу
`economy.json`, — 400, см. [06-formuly.md](docs/sdacha/06-formuly.md)). Её надо разложить по трём конвертам: **НУЖНО**
(еда, жильё, корм питомцам), **ХОЧУ** и **ЦЕЛЬ** (накопления). Потом ребёнок решает, на что
тратить силы Финни: работать сменами в городе или отдыхать. Копить можно на питомца,
транспорт или жильё получше.

Неделя — **7 игровых дней** (`day_cycle.days_per_week` = 7). Каждое дело дня — смена, досуг — тратит
силы ⚡. День кончается, когда ребёнок нажал «Спать» или когда сил не хватает ни на одно дело. Сон
утром возвращает силы: не меньше 10, а если сил много — добавляет немного, но не больше 20
(`day_cycle.sleep_rule`). После 7-го дня оплачиваются счета, а план сравнивается с фактом.
Каждая неделя приносит очки роста, и по ним Финни переезжает: «В деревне» → «В городе» → «В Москве».

Финни ест один раз в день (`day_cycle.meals_per_week` = 7). Сытый Финни утром бодрее (+2 ⚡), голодный —
слабее и грустнее (−2 ⚡, −2 😊); если ребёнок не купил еду, Финни ест дома (`day_cycle.satiety_*`,
`home_meal_daily`). Голод не пугает: он ничего не отнимает, кроме этих двух небольших штрафов на утро.
Настроение после смены зависит от работы: Финни нравятся финансы, поэтому интересная работа с ценами радует,
однообразная огорчает (`day_cycle.mood_kinds`). Оплата и силы смены зависят от настроения 😊 на момент смены
(`day_cycle.mood_pay_live`): оплата = ставка × (1 + 0,006 × (😊 − 50)) в границах 0,8–1,2 от ставки; при 😊 ≤ 40 смена
стоит на 1 ⚡ больше, при 😊 ≥ 60 — на 1 ⚡ меньше. На смене бывает везение и невезение — «покупатель точно знает,
что ищет» или «заедает касса» (`day_cycle.shift_luck`: шанс 0,35, 35 сценариев).
Примерно на каждой второй смене перед началом бывает вопрос с двумя вариантами — например «взять второй заказ»
(больше монет, меньше сил); выбор и есть начало смены (`day_cycle.shift_choices`, 28 вопросов,
[06-formuly.md](docs/sdacha/06-formuly.md)). Объяснения «почему так» — везение в итоге смены, «?» у настроения,
«Как это считается» у опыта, сон (`day_cycle.explain_ui`, [08-ux-ui.md](docs/sdacha/08-ux-ui.md)). В городе строка «Куда идти»
подсказывает нужное здание и ведёт туда Финни ([08-ux-ui.md](docs/sdacha/08-ux-ui.md)); когда подсказывать нечего —
«Нажми на здание или веди Финни пальцем». Надбавка за опыт на доске работ — словами и монетами («за опыт оплата больше на пятую часть
(+N монет)»), строка есть, только если опыт прибавил хотя бы монету. «Счета недели» в итогах совпадают с фактом «Нужно»
в плане: еда посреди недели плюс счета в конце, по журналу. У енота четыре облика в толстовках разного цвета. Не больше одного события в день,
всего событий 52 (`day_cycle.max_events_per_day`, `events.json`).

Три ресурса: 💰 монеты, ⚡ энергия (0–20, `day_cycle.energy_max`), 😊 счастье (0–100), и шкала
сытости 0–100. Все формулы описаны в [06-formuly.md](docs/sdacha/06-formuly.md).

**Жёсткие границы ТЗ.** В игре только игровая валюта. Нет реальных платежей, рекламы,
подписок, случайных платных наград и общения между детьми. Персональные данные не собираются,
приложение не ходит в сеть, всё хранится на устройстве. Подробно — в
[09-razresheniya-i-dannye.md](docs/sdacha/09-razresheniya-i-dannye.md).

## Состав репозитория

| Путь | Что |
|---|---|
| [`app/finlit/`](app/finlit/) | Flutter-приложение (одна кодовая база, Android 8.0+) |
| `app/finlit/lib/domain/` | Правила игры на чистом Dart, без Flutter: неделя, день, экономика, работа, события, рост |
| `app/finlit/lib/domain/world/contract.dart` | Контракт мира: снимок ресурсов, действия, результат с причиной |
| `app/finlit/lib/data/` | Загрузка контента из JSON и хранение на устройстве |
| `app/finlit/lib/features/` | Экраны |
| `app/finlit/assets/content/world/` | Копия `content/*.json`, которая едет в сборку |
| `app/finlit/test/` | Автотесты: домен, экраны, контент, доступность, манифест |
| [`content/`](content/) | Учебный контент и все числа экономики: `economy.json`, `jobs.json`, `events.json`; симулятор недельной модели `sim/economy_sim.py`; симулятор режима 7 дней на настоящем движке — `app/finlit/tool/economy7_sim_test.dart` |
| [`assets/`](assets/) | Исходники пиксель-арта (здания, комната, Финни, питомцы) и реестр `registry.json` |
| [`docs/sdacha/`](docs/sdacha/.) | Документация по §5 ТЗ, 12 пунктов |
| `LICENSES/` | Тексты лицензий шрифтов и перечень зависимостей |

Числа в коде не пишутся: экономика, работа и события читаются из `content/*.json`.
Чтобы добавить событие или поменять цену, достаточно поправить JSON (ТЗ 2.5.14), логику
трогать не нужно.

## Быстрый запуск

Нужны Flutter 3.41.7 (на нём собирает CI) и Android SDK. Полные требования к окружению — в
[02-okruzhenie-i-sborka.md](docs/sdacha/02-okruzhenie-i-sborka.md).

```bash
cd app/finlit
flutter pub get
flutter analyze        # ожидается «No issues found!»
flutter test           # все тесты зелёные
flutter run            # на подключённом телефоне или эмуляторе
```

🔴 В пути к репозиторию не должно быть кириллицы: на таком пути Flutter роняет analysis server
с `FormatException`, и в сообщении про путь не сказано ни слова.

Релизный APK:

```bash
cd app/finlit
flutter build apk --release
# → build/app/outputs/flutter-apk/app-release.apk
```

Без файла `key.properties` рядом с `key.properties.example` (каталог `app/finlit/android/`) релиз подписывается
отладочным ключом, и такой APK отдавать нельзя. Как подключить ключ и проверить подпись — в
[02-okruzhenie-i-sborka.md](docs/sdacha/02-okruzhenie-i-sborka.md).

Баланс экономики проверяется симуляторами. Недельная модель (нужен только Python 3.10+):

```bash
python content/sim/economy_sim.py --weeks 5
```

Режим 7 дней — на настоящем движке игры (из `app/finlit`):

```bash
flutter test tool/economy7_sim_test.dart
```

## Как проверить сценарий Приложения А

Приложение открывается сразу в новом мире: знакомство → комната Финни. При первом заходе в комнату идёт
обучалка-прожектор из 6 шагов (привет, аренда, магазин, опыт, настроение, «?»; `day_cycle.tutorial_ui`).

**Режим проверки для эксперта:** в комнате нижнее меню «Ещё» → «Настройки» → **«Режим проверки»** → решить пример на
умножение (экран «Проверка», маршрут `/w/demo`). Раздела «Взрослым» в меню комнаты в сборке нет (`adult.section` = false);
экран взрослого открывается только из «Режима проверки» (список «Экраны» → «S14 · Взрослым»). Там:

- «Автопилот»: «Сыграть 1 неделю», «Сыграть 5 недель», «Дойти до 3-й стадии» — недели проигрываются теми же действиями,
  что у ребёнка, журнал автопилота показан ниже;
- «Закончить неделю» — работает, пока неделя идёт: засыпает день за днём до итогов недели (подпись на экране:
  «Как «Спать»: дальше счета и итоги»);
- «Полная ⚡» — кнопка без действия: на ней написано «Пока нет: демо-записи для ⚡ в журнале нет». Силы
  Финни восстанавливает «Спать»;
- «Открыть все профессии» и «Показать событие» — открывают работы без покупок и любое из 52 событий сразу;
- «Приложение А: N из 12» — отметки шагов по журналу игры;
- «Открыть город» — стадия «город» без монет (после этого кнопка неактивна: «Финни уже в городе»); «Дать 1000 монет» / «Дать 5000 монет» — свободные монеты,
  переживают перезапуск;
- «Экраны» — переход на любой экран мира;
- «Начать игру заново» — стирает прогресс после подтверждения (отдельного тестового профиля нет); то же есть в «Ещё» → «Настройки», за тем же примером на умножение.

Шаги и ожидаемый результат — в [10-testy-i-proverka.md](docs/sdacha/10-testy-i-proverka.md). Без установки — веб-демо
https://finni.archifex.space/demo/.
